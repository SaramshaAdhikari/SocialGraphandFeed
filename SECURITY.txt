# 🔍 PHASE 1 — INPUT & EXECUTION ATTACKS

## Test ALL endpoints with:

1. SQL injection payloads:

   * `' OR 1=1 --`
   * UNION-based payloads
   * malformed numeric inputs

2. XSS payloads:

   * `<script>alert(1)</script>`
   * event handlers
   * JSON-based injection

3. Malformed payloads:

   * missing required fields
   * extra unknown fields
   * wrong data types
   * deeply nested JSON

4. Boundary abuse:

   * extremely large payloads
   * extremely long strings

---

## VERIFY:

* Strict schema enforcement (reject unknown fields)
* No partial execution
* Deterministic 400 responses
* No DB mutation on failure

---

# 🔐 PHASE 2 — AUTH & SESSION ATTACKS

Simulate:

* session fixation (reuse old session after login)
* session reuse after logout
* missing session regeneration
* cookie tampering

---

## VERIFY:

* session ID rotates on login
* invalid sessions fail immediately
* logout fully invalidates session
* cookie flags:

  * HttpOnly
  * Secure (if HTTPS)
  * SameSite enforced

---

# 🧾 PHASE 3 — AUTHORIZATION BREAKING

Attempt:

* accessing other users’ data
* modifying other users’ content
* bypassing ownership checks

---

## VERIFY:

* all queries are owner-scoped
* write operations enforce ownership at DB level
* unauthorized access always fails

---

# ⚡ PHASE 4 — RATE LIMITING & ABUSE

Simulate:

* brute-force login attempts
* rapid posting
* spam messaging
* repeated identical API calls

---

* server-side rate limits exist
